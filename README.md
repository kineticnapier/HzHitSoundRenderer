# HzHitSoundRenderer v1.0.0

高KPS / Hz Charting 用のヒット音PCMレンダラーです。

## 基本方針

- ヒット音イベントは間引きません。
- 元の hitSound `AudioClip` のPCMをそのまま出力バッファへ重ねます。
- シンセ化、Hz芯追加、胴鳴り追加、密度ゲイン、リミッター、ソフトクリップ、最終音量ブーストは使いません。
- `ヒット音倍率` は0〜1の単純な線形倍率だけです。1.0が元音量です。
- `コピーする長さ 秒` は0が既定で、元音全体を使用します。

## v1.0.0

生成したPCMヒット音をADOFAIの再生ライフサイクルに追従させました。

次の場合に、再生中・予約済みの生成音と事前焼きキャッシュを即座に停止します。

- ゲームオーバーが成立した時
- レベルエディタで再生モードから編集モードへ戻る時
- リスタート時
- レベルエディタを抜ける時
- メインメニューへ戻る時
- シーン遷移・再生元シーンのアンロード時
- MOD無効化・アンロード・ゲーム終了時

Unityの `Destroy()` はフレーム末尾まで遅延するため、v1.0.0では生成した全`AudioSource`へ先に`Stop()`を呼び、GameObjectを無効化してから破棄します。これにより、停止操作後に予約音が鳴り始める問題も防ぎます。

## 使い方

UMMで有効化し、再生方式を選んで通常どおり譜面を再生してください。

- `分割先読み`: 軽量で編集確認向け
- `全セグメント事前焼き`: 再生前に全セグメントを生成
- `全体1本焼き`: 境界ノイズを避けるため全体を1本のAudioClipへ生成

音が強すぎる場合は `ヒット音倍率` を下げてください。音量を1倍より上へ増幅する機能や音色加工はありません。
